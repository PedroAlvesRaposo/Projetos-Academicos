# **Plataforma Social para Times de E-sports**

Este projeto consiste no desenvolvimento de uma plataforma digital integrada ao Sistema de Avaliação e Seleção Automática para Times de E-sports, destinada exclusivamente aos candidatos classificados no processo seletivo.

A aplicação funciona como uma rede social privada, permitindo a interação entre os jogadores aprovados e o instrutor responsável pelo time, além de fornecer recursos voltados ao acompanhamento de desempenho e evolução individual.

O sistema foi desenvolvido como uma aplicação web utilizando HTML e CSS, juntamente com um pequeno banco de dados responsável por armazenar as credenciais de login dos jogadores e do treinador, garantindo controle de acesso à plataforma e persistência básica das informações.

O objetivo principal da plataforma é centralizar comunicação, treinamentos e métricas de progresso em um único ambiente, promovendo maior engajamento, organização e transparência no preparo dos atletas para campeonatos.

## **Funcionalidades principais**

• Autenticação dos jogadores classificados no sistema de seleção

• Comunicação entre membros do time e instrutor (chat ou mensagens)

• Publicação de fotos dos treinos e atividades

• Acesso a uma página de treinamentos personalizada pelo treinador

• Visualização de progresso individual e desempenho competitivo

• Acompanhamento de métricas voltadas à preparação para campeonatos

Este projeto tem caráter acadêmico e foi desenvolvido com foco na aplicação prática de conceitos de engenharia de software, incluindo levantamento de requisitos, modelagem do sistema, desenvolvimento de funcionalidades e integração entre plataformas.
