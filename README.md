# Projetos-Academicos

Este diretório reúne diversos trabalhos desenvolvidos ao longo do meu período acadêmico, abrangendo atividades práticas, projetos, exercícios e estudos realizados durante a graduação.

Os arquivos aqui presentes refletem minha evolução técnica, capacidade de análise e aplicação de conceitos aprendidos em sala de aula, incluindo áreas como programação, testes de software, arquitetura de computadores, microcontroladores e desenvolvimento de sistemas.

O objetivo deste espaço é centralizar e documentar minha trajetória acadêmica, servindo como registro de aprendizado e também como parte do meu portfólio profissional.

Cada projeto contém sua própria documentação ou descrição quando aplicável.
